A single model can answer a question. A group of agents can split a problem, check each other's work, and call tools in parallel.

## A minimal loop

```python
def run(task, agents):
    plan = agents["planner"].plan(task)
    results = [agents["worker"].do(step) for step in plan]
    return agents["reviewer"].check(results)
```

## Where it breaks

- Agents repeat each other's mistakes.
- Costs grow with every extra call.
- Debugging a conversation is harder than debugging a function.

> Add agents only when one agent has stopped being enough.
